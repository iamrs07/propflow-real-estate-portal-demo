PropFlow - Buyer Handover Guide

Quick Start:
1. git clone https://github.com/iamrs07/propflow-real-estate-portal-demo.git
2. npm install
3. npm run dev
4. Open http://localhost:3000

Demo: PROPFLOW_DEMO_MODE=1

Deploy to Vercel: import repo, set env vars, deploy.
Build: npm run build && npm start
